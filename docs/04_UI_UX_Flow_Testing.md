# UI/UX Flow and Testing

### Overview

This document describes the user interface flow and the testing checklist for the educational cyber security game.

---

# Game Flow

```
Start Screen
      ↓
Choose Character
      ↓
Introduction
      ↓
Tutorial
      ↓
Scenario 1
      ↓
Feedback
      ↓
Scenario 2
      ↓
Feedback
      ↓
Scenario 3
      ↓
...
      ↓
Scenario 8
      ↓
Final Score
      ↓
Congratulations Screen
```

---

# User Interface Guidelines

The interface should be simple and easy for children.

## Colors

- Bright colors
- High contrast
- Friendly appearance

## Text

- Large font
- Short sentences
- Easy vocabulary

## Buttons

- Large clickable buttons
- Clear labels
- Easy navigation

---

# Difficulty Progression

The game should gradually become more challenging.

| Level | Difficulty |
|--------|------------|
| 1–2 | Easy |
| 3–5 | Medium |
| 6–8 | Hard |

---

# Testing Checklist

## Gameplay

- All buttons work correctly.
- The player can complete every scenario.
- The score updates correctly.
- The game ends properly.

---

## User Interface

- Text is readable.
- Buttons are easy to click.
- Images load correctly.
- Animations play correctly.

---

## Educational Content

- Correct answers display positive feedback.
- Wrong answers explain the mistake.
- The animal mentor appears after every decision.
- Scenarios are easy to understand.

---

## Performance

- No crashes.
- Fast loading.
- Smooth animations.
- No missing images.

---

# Expected Learning Outcomes

After completing the game, children should be able to:

- Recognize suspicious links.
- Create strong passwords.
- Protect personal information.
- Avoid online scams.
- Understand basic cyber security rules.
- Make safer decisions while using the internet.
