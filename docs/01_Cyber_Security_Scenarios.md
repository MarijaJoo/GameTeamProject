# Cyber Security Scenarios

### Overview

This document contains the cyber security scenarios used in the educational game. The purpose of these scenarios is to teach children safe online behavior through simple, interactive, real-life situations.

The scenarios are designed for young children and gradually increase in difficulty. Each scenario presents a situation with two possible choices. After the player makes a decision, the game provides immediate feedback through the animal mentor.

---

# Scenario 1 – Suspicious Link

**Situation**

You receive a message saying:

**"Click here to get a FREE toy!"**

### Choices

- Click the link
- Delete the message ✅

### Correct Answer

Delete the message.

### Learning Goal

Children learn that links from unknown people can be dangerous and may contain viruses or scams.

---

# Scenario 2 – Creating a Password

**Situation**

You need to create a password for your new game account.

### Choices

- 123456
- Tiger!98 ✅

### Correct Answer

Tiger!98

### Learning Goal

Children learn that strong passwords should contain letters, numbers, and symbols.

# Scenario 3 – Stranger Asking for Personal Information

**Situation**

Someone online asks:

**"What is your home address?"**

### Choices

- Tell them
- Do not share it ✅

### Correct Answer

Do not share it.

### Learning Goal

Children should never share personal information with strangers.

---

# Scenario 4 – Friend Sends a Strange Link

**Situation**

Your friend suddenly sends a strange link without saying anything.

### Choices

- Open it immediately
- Ask your friend if they really sent it ✅

### Correct Answer

Ask your friend first.

### Learning Goal

Sometimes accounts get hacked. Always check before opening unusual links.

# Educational Objectives

After completing all scenarios, players should be able to:

- Recognize suspicious links.
- Create strong passwords.
- Protect personal information.
- Identify unsafe online behavior.
- Avoid online scams.
- Understand why software updates are important.
- Use safe internet habits in everyday life.
